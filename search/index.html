最近の検索

    GitHubの鍵(最初に一度だけ)

    1. GitHubで「Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token」を開く。
    2. Repository access は「Only select repositories」で kimpilla/ai-memory だけを選ぶ。
    3. Permissions の「Contents」を「Read and write」にする。期限は好きな長さで。
    4. できた鍵(github_pat_ で始まる文字)を下に貼って「保存」。鍵はこの端末のブラウザの中にだけ残る。
