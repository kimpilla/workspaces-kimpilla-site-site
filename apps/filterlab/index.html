フィルターの ひみつ

シンセの「フィルター」が、音のどこを削っているのかを、見て、聞いて確かめるページ。声(波)を選んで、あかるさを動かすと、3つのグラフが一緒に変わる。

① だれの こえに する?(おして みよう)

ぼうの たかさは、その こえに ふくまれる おとの つよさ。ぼうの したの すうじは、もとの おとの なんばいの おとか(1ばい = もとの おと)。みぎに ある ぼうほど、たかい おと(倍音)。ぼうが ない ところは、その おとが ふくまれていない ということ。

② あかるさと とがりを うごかそう

くち=あかるさ / め=とがり
☀️ あかるさ
🔔 とがり

スライダーを うごかすと、したの グラフが いっしょに かわるよ。

📈 フィルターの カーブ(どの たかさの おとを とおすか)

よこ = おとの たかさ、たて = とおる おおきさ。🟠 = いまの こえの おとの いち。

〰️ なみの かたち(まえ → あと)

フィルターの まえフィルターの あと

たかい おとが けずられると、なみの かどが まるくなる。ギザギザが なめらかな なみに ちかづく。

📊 たかい おとの ぼう(まえ → あと)

わく = もとの おとオレンジ = フィルターを とおった おと

ひとつの こえは、いろんな たかさの おと(ぼう)の あつまり。みぎの たかい ぼうが ふえるほど、「あかるい・ギザギザ」な おとに なる。サイン波は、いちばん ひだりの 1ぼんだけ。だから、フィルターを うごかしても、けずる ものが なくて ほとんど かわらない。

③ じどう ワウワウ

あかるさを じどうで ゆらゆら うごかす しかけ。くちが ひらいたり とじたり、「ワウワウ」と きこえるよ。うえの かおも いっしょに うごくよ。

ワウワウ中は、カーブの おれる ばしょが ゆらゆら ひだりみぎに うごく。

🔍 ワウワウで なにが おきてるの?

  1. あかるさ(おれる ばしょ)が、じどうで たかい ↔ ひくいを くりかえす。(1びょうに 1.2かい くらい)
  2. たかい とき = くちが ひらいて あかるい おと、ひくい とき = くちが とじて こもった おと。
  3. あかるい・こもる・あかるい…が つづくから、「ワウ ワウ」と きこえる。
  4. たかい おとが すくない こえは、けずる ものが ないから ワウワウが きこえにくい。

おとなの人へ(なにが起きているか)

  • フィルター: ここでは「ローパス」(低い音を通して、高い音を削る)。カットオフ(あかるさ)より上の音を、1オクターブごとに約12dB(2次)ずつ弱める。「とがり」(レゾナンス、Q)を上げると、カットオフ付近だけが持ち上がる。
  • カーブ: Web Audio の BiquadFilterNode の周波数応答(getFrequencyResponse)を、そのまま描いている。軸は、横が対数の周波数、縦がデシベル。
  • 波形の前後: 波を、倍音(1倍、2倍、3倍…の音)の足し算として、倍音ごとに、フィルターの振幅と位相のずれを掛けて描き直している。位相が変わるので、削る前と後で、山の位置も少しずれる。
  • 棒グラフ: 倍音の強さ。小さい倍音も見えるよう、高さは平方根で描いている。ノイズは、すべての高さの音が同じ強さで混ざっているので、棒は同じ高さになり、フィルターが削る様子が、そのまま見える。
  • じどう ワウワウ: カットオフを、約1.2回/秒でゆっくり上下させる。グラフの折れ目が、音と同じ動きをする。
